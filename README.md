# ALJESI Browser | متصفح الجيسي

متصفح Android مبني باستخدام Flutter و`flutter_inappwebview`، بواجهة سوداء ولمسات خمرية.

## الميزات الموجودة في هذه النسخة
- تصفح صفحات الويب والبحث من شريط العنوان.
- المفضلة وحفظها محلياً.
- قائمة التحميلات وتنزيل الملفات إلى مجلد يختاره المستخدم.
- وضع سطح المكتب.
- فتح ترجمة الصفحة عبر Google Translate.
- مانع إعلانات أولي يعتمد على حجب مجموعة نطاقات معروفة.
- اختبار اتصال مبسط يعرض نتيجة من 100.
- حفظ نصوص الحقول لكل موقع عبر الضغط المطوّل على حقل، وإظهار اقتراح صغير عند التركيز على حقل محفوظ.
- خلفية نجوم متحركة وأزرار تنقل.

## البناء
يتطلب Flutter 3.19 أو أحدث وAndroid SDK.

```bash
flutter pub get
flutter create . --platforms=android
flutter pub get
flutter build apk --release
```

في حال أنشأ `flutter create` مجلد `android`، اتركه كما هو ثم نفّذ البناء.

## ملاحظات تقنية مهمة
- لا يمكن للتطبيق تجاوز سرعة الشبكة أو سحب إنترنت أكثر مما يوفره اتصال الهاتف. اختبار السرعة يعطي مؤشراً تقريبياً مبسطاً وليس شهادة قياس احترافية.
- اختيار مجلد التنزيلات يعتمد على منتقي ملفات Android وصلاحيات النظام. بعض إصدارات Android قد تفرض قيوداً على الكتابة إلى مجلدات معينة.
- مانع الإعلانات الحالي أساسي، وليس بديلاً كاملاً عن قوائم حجب متخصصة أو أدوات حماية متقدمة.
- ميزة حفظ الحقول تعمل داخل صفحات الويب التي تسمح بالتفاعل المعتاد مع حقول الإدخال؛ بعض المواقع الحساسة قد تمنعها.

## GitHub Actions
يوجد سير عمل في `.github/workflows/android.yml` ينشئ هيكل Android القياسي ثم يبني APK عند كل push.
